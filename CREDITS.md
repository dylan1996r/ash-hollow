# Credits

Ash Hollow is a fully AI-created game experiment with human direction and approval. This file records AI involvement and third-party assets used in the public browser demo.

## AI and Human Involvement

- **OpenAI Codex / ChatGPT**: concept development, planning, implementation, documentation, local validation, repository setup, and deployment support.
- **Claude Code with Claude Opus 4.7**: planned future code review, debugging, architecture feedback, and iteration assistance.
- **Human direction**: tone, priorities, approval, taste, and iteration requests.

## License Policy

- CC0 assets are preferred.
- CC-BY assets may be used later only when creator, title, source URL, license URL, local path, usage, and modification notes are recorded.
- Assets with noncommercial, no-derivatives, GPL, unknown, or no-redistribution terms should not be included.
